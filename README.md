# PUCRS - Projeto de Fundamentos de Sistemas Web

## Universo Pet - E-commerce Petshop

Projeto desenvolvido para a disciplina de Fundamentos de Sistemas Web da PUCRS. Na Fase 1, foi construída a estrutura semântica com HTML5; na Fase 2, o sistema evoluiu com estilização e carrossel via Bootstrap 5 e CSS, interatividade em JavaScript, formulário de cadastro de cliente e pet com agendamento e melhorias de acessibilidade.

## Requisitos Atendidos (Fase 1 e Fase 2)

- Estrutura semântica HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<dl>`, `<footer>`) e organização em arquivos (`index.html`, `css/style.css`, `js/script.js`).
- Catálogo com 3 categorias de produtos (Acessórios, Rações, Higiene e Limpeza) contendo 2 itens cada, com imagem, descrição, valor e adição ao carrinho.
- Carrossel de destaques com Bootstrap 5 e funções temporais em JavaScript (data/hora em tempo real, status de atendimento e bloqueio de datas passadas no calendário).
- Formulário de cadastro do cliente e do pet e agendamento de serviços (Banho e/ou Tosa, modalidade tele-busca ou entrega no local, com seleção de dia e horário).
- Acessibilidade para deficientes visuais com descrições `alt` nas imagens, labels vinculados, foco visível e modo de alto contraste.
