# PUCRS - Projeto de Fundamentos de Sistemas Web

## Universo Pet - E-commerce Petshop

Projeto desenvolvido para a Fase 1 da disciplina de Fundamentos de Sistemas Web da PUCRS. O foco desta etapa é a estruturação semântica de uma página web utilizando exclusivamente HTML5.

## Requisitos Atendidos (Fase 1)

* Estrutura semântica correta (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* Catálogo com 3 categorias de produtos (Acessórios, Rações, Higiene e Limpeza) contendo 2 itens cada.
* Seção de serviços detalhando Banho e Tosa (com e sem tele-busca) estruturada com listas de descrição (`<dl>`).
* Zero CSS ou JavaScript (serão adicionados na Fase 2).
